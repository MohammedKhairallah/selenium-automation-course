# Selenium Test Automation Course

Code I wrote while learning test automation with Java and Selenium WebDriver.

## Tools & Technologies
- Java
- Selenium WebDriver
- Maven
- IntelliJ IDEA

## What's Inside
| Package | Topic |
|---|---|
| `Alerts` | Handling JavaScript alerts |
| `dynamicLocators` | Dynamic locators |
| `FindingWebElements` | Locator strategies (ID, CSS, XPath, ...) |
| `HandlingCheckboxesandRadioButton` | Checkboxes and radio buttons |
| `HandlingDropDowns` | Dropdowns |
| `InformationAboutWebElement` | isDisplayed, isEnabled, getText, attributes |
| `IntroductionRestAssured` | Basic API tests with Rest Assured |
| `KeyboardActions` | Keyboard actions |
| `MouseActions` | Right click, hover, double click, drag and drop |
| `Screenshot` | Taking screenshots |
| `TakeActionOnElement` | Clear, sendKeys, click, upload files |
| `WaitingStrategies` | Implicit, explicit, and fluent wait |
| `WheelActions` | Mouse wheel actions |
| `Workingwithwindows` | Windows and tabs |

## How to Run
1. Clone the repository:
```
   git clone https://github.com/MohammedKhairallah/selenium-automation-course.git
```
2. Open the project in IntelliJ IDEA.
3. Wait for Maven to download the dependencies.
4. Run any test class from `src/test/java`.
